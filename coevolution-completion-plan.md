Authorized: Leonardo's request to complete the remaining implementation, 2026-09-20.
Each mechanism remains independently selectable. Implementation is not evidence of
better intelligence; promotion needs paired experiments and held-out results.

## Execution constraint from Leonardo

After a reported desktop freeze, Leonardo requires GPU-only numerical validation.
Do not run CPU test suites, standalone CPU oracles, or the mixed CPU/GPU validator.
Use short real-GPU checks; reject software adapters (llvmpipe/lavapipe). File inspection
and necessary build/launch work remain on the host. Compile only the needed target,
one build job at low priority, with no concurrent build/test processes. Earlier CPU
test results are historical evidence, not permission to repeat those commands.

## Explicit remaining gates from the broader proposal

Age-dependent sensor development and calibrated neural metabolic costs are not
implemented here; neither are arbitrary new organs or dynamically allocated brains.
The implemented scope is [COEVOLUTION-RUNTIME.md](docs/COEVOLUTION-RUNTIME.md).
No statistically supported learning gain was established. The combined arm regressed
and remains off by default. Long-life/ecosystem resume, trained curriculum transitions,
lineage-aware lab-ui integration and visual browser validation remain open. The
browser policy blocked local-file inspection; do not count HTML export as visual proof.

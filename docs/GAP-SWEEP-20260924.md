Read-only sweep of the school work (six audit fronts + direct reading of the seed-11

## P0 — the stop lesson selects crawlers, and the metric cannot see it

Evidence, `school-stop-envelope-from-move-20260923/stop-from-move-envelope-s11/school_result_gen*.json`:

| gen | start 0: median vmax / distance | start 1 | start 2 | strict successes (closing tick) |
|---|---|---|---|---|
| 0 | 10.3 m/s / 40.1 m | 13.2 / 40.1 | 13.2 / 40.2 | 0 (all 48 overshoot at 9–11 m/s) |
| 8 | 1.5 / 13.5 | 2.1 / 24.6 | 4.3 / 31.6 | 1 (tick 1175 of 1280) |
| 47 | 1.3 / 10.8 | 1.4 / 12.7 | 3.6 / 26.9 | 3 (ticks 1272, 1151, 1145) |

The move champion enters the goal area at 9–11 m/s and passes through. Eight generations
later the population moves at 1.3–1.5 m/s and never reaches the goal on starts 0 and 1
(status `truncated`, code 0, 13 of 16 replicas). The only "successes" close in the last
second of the horizon: the champion's max speed on start 2 is 3.007 m/s (v_min is 3.0),
then it creeps 28 m in 18 s and dwells into the deadline.

1. **Timing out is free, overshooting costs 200.** `src/gpu/school.wgsl:95` scores
   `1000·success + 500·progress − 200·failed …`; the horizon closes with status 3
   (`close(k,s,3.0,0.0)`, `school.wgsl:238-243`), which is *truncated*, not *failed*.
   `src/bin/gpu_evolve/school_batch.rs:54-71` subtracts `worst_failure_penalty` (200/300)
   from the K-start mean only for status 2. Numbers: overshooter 300 − 200 = 100; crawler
   that never arrives (176 + 264 + 200)/3 − 0 = 213. Crawling dominates by construction.
2. **The three starts never change.** `school_batch.rs:112-119` `required_start_count`
   returns K when K > 1, so `starts.len() == K`; `start_index` (`:124-132`) rotates by
   `generation_idx·K mod K = 0`. `organism_city.rs:174` builds the city without a seed.
   Result: start 0 = (99,156), start 1 = (99,348), start 2 = (291,156), heading (0,−1),
   30 m each, identical for all 48 generations and for seeds 7 and 11. K = 3 is three fixed
   exams, not robustness. The manifest label `same_deterministic_batch_per_genome`
   (`main.rs:5266`) is honest; the doc phrase "distinct starts" is not.
3. **Mean across starts lets one start pay for all.** `school_batch.rs:36-71`: champion
   at gen 47 = (2102 + 176 + 264)/3 = 847, beating every all-round genome. `worst_score`
   is computed and written to the record but not used for selection.
4. **The v_min gate is "ever reached", then anything goes.** `school.wgsl` PHASE is
   monotonic; touching 3.0 m/s once, then coasting for 17 s, counts. No deadline, no
   minimum mean speed, no time-to-stop in the score.
5. **The brake channel is selected out and nothing can see it** (recorded in
   SCHOOL-STOP-ENVELOPE-20260923.md §5c): brake intent negative, mapper clips to 0
   (`organism_action.wgsl:61`); exclusive pedals, static rest and low-speed brake are
   hardcoded on with no CLI switch (`organism_tick.rs:27,237-238`), so no paired A/B is
   possible; the 6 m excess clamp saturates (edits for `--school-stop-envelope-clamp-m`
   are in the tree, unbuilt).

What this implies: the envelope and shaping A/Bs (§5.1, §5b) measured a population that
had already stopped moving. Any stop result before items 1–4 are fixed is a result about
crawling.
